FREELANCER LANDING PAGE TEMPLATE
================================

Thanks for buying! This is a one-page website template for freelancers
and consultants. No coding tools or frameworks needed: it's a single
HTML file.

WHAT'S INSIDE
-------------
freelancer-landing-template.html   The template
README.txt                         This guide

HOW TO EDIT (10 minutes)
------------------------
1. Open the HTML file in any text editor (VS Code, Notepad, TextEdit
   in plain-text mode).
2. Search for "YOUR" and replace it with your own name and details.
3. Replace the placeholder text in each section: services, results,
   process steps, testimonial, and pricing.
4. Replace "you@example.com" with your real email address.
5. Update the <title> and meta description near the top (this is what
   shows in Google results).
6. Save the file, then double-click it to preview in your browser.

CHANGING COLORS AND FONTS
-------------------------
At the top of the file, find the ":root" block. Change these values:

  --bg        page background
  --ink       main text and dark sections
  --accent    buttons and highlights
  --signal    secondary highlight (availability, stats)

Fonts are loaded from Google Fonts. To change them, swap the font names
in the <link> tag and in the --display and --body lines.

HOW TO PUBLISH IT (free options)
--------------------------------
- Netlify Drop: go to app.netlify.com/drop and drag in your folder.
  Rename the file to index.html first.
- GitHub Pages: create a repo, upload index.html, then turn on Pages
  in Settings.
- Your own hosting: upload index.html to your web host.

TIPS
----
- Show real numbers in the Results section. Specific beats impressive.
- Update the Availability card every month, or delete it if you don't
  want it.
- Delete any section you don't need. Each one is self-contained.
